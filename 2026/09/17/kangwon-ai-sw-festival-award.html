DAISY LAB의 김남호, 김지호·권태성 학부연구생(지도교수: 강은송)이 「2026 강원권 AI·SW 페스티벌」에서 각각 장려상과 특별상을 수상했습니다! 🎉

DAISY LAB 김남호 학부연구생이 「2026 강원권 AI·SW 페스티벌」 우수 프로젝트 작품 경진대회에서 공개 의료 LLM 5종의 서빙 인프라 보안 검증 연구로 장려상(공동 사업단장상)을, 김지호 학부연구생이 포스터 발표 부문에서 AI 기반 스마트 간호 업무 지원 시스템 MedClaw로 특별상(공동 사업단장상)을 수상했습니다! 본 행사는 강원대학교 SW중심대학사업단 주관, 한림대학교·한라대학교·연세대학교 미래캠퍼스 협력으로 개최되었습니다.

💡 출품작 소개

김남호 — 우수 프로젝트 작품 경진대회

공개된 의료 특화 LLM을 실제로 서빙할 때 발생하는 인프라 보안 취약점을 검증한 연구입니다. MedGemma(4B/27B), Meditron(7B/70B), MedAlpaca(13B) 등 총 5종의 공개 의료 LLM을 대상으로 서빙 인프라 보안 검증 실험을 수행했습니다.

의료 LLM 연구가 주로 모델의 진단 성능에 집중되어 온 반면, 본 연구는 모델을 실제 서비스로 배포하는 단계에 주목했습니다. 실험 결과 API 인증, 파라미터 검증, 로그 보안에서 모델 종류와 규모에 무관하게 공통적으로 나타나는 취약점을 확인하였고, 이를 통해 안전한 의료 LLM 배포를 위해서는 모델 성능뿐 아니라 인프라 보안이 함께 확보되어야 함을 제시했습니다.

김지호, 권태성 — 포스터 발표: MedClaw

MedClaw는 간호사의 업무 파악, 오더 해석, 인수인계 작성, 환자 교육 자료 제공을 지원하는 에이전틱 워크플로우 기반 멀티 에이전트 시스템입니다. React 프론트엔드와 FastAPI 백엔드로 구성되며, 중앙의 Orchestrator Agent가 요청을 수신해 기능별 하위 에이전트로 작업을 분배합니다.

의료 AI 연구가 주로 진단·예측 모델의 정확도에 집중되어 온 반면, 본 연구는 간호 업무 흐름 자체를 설계 대상으로 삼아 LLM 에이전트를 임상 워크플로우에 배치했습니다. RAG 기반 근거 검색과 고위험 오더 검증 루프로 환각 위험을 통제하고 간호 업무 경험자의 평가를 거침으로써, 의료 현장에 적용 가능한 LLM 기반 업무 지원 시스템의 설계 방향을 제시했습니다.
